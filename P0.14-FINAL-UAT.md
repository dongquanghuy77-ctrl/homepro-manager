# P0.14-HARD-FIX FINAL PRODUCTION REPORT

## 1. ROOT CAUSE
Route `/nhan-vien` bị crash 500 Internal Server Error trong quá trình Server-Side Rendering (SSR). Nguyên nhân gốc rễ là do query trực tiếp vào bảng `leave_balances` trong cơ sở dữ liệu (thông qua Drizzle ORM) nhưng bảng này chưa được migrate đầy đủ hoặc bị lỗi data schema trên môi trường thực tế, gây ra Exception chưa được catch.
Khi SSR ném ra 500 error, Client-side router của Next.js (bên trong App Router) không thể hydrate được payload RSC (React Server Components), dẫn đến việc Client Route đánh giá đây là lỗi bảo mật/phiên bản và kích hoạt hard-reload hoặc Middleware can thiệp đá văng session ngược về `/login`.

## 2. FILES CHANGED
- `src/app/(worker)/nhan-vien/page.tsx`: Sửa đổi cấu trúc gọi Database bằng Drizzle ORM tại phần lấy thông tin `leaveBalances`. Thêm fallback `.then(rows => rows as any[]).catch(() => [] as any[])` để bọc an toàn truy vấn. Nếu bảng bị lỗi hoặc chưa tồn tại, hệ thống sẽ im lặng trả về array rỗng thay vì làm sập toàn bộ route.
- `scripts/dump_roles.ts`: Sửa lỗi type mismatch TypeScript (`users.isActive` -> `users.active`).
- `scripts/uat_p014.ts`: Viết lại hệ thống giả lập Playwright (thay vì dùng `page.evaluate` dễ bị huỷ context bởi Next.js soft-navigation, đã chuyển sang cơ chế `waitForLoadState('networkidle')` và API request trực tiếp từ context).
