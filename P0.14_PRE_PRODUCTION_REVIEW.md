# P0.14 PRE-PRODUCTION REVIEW

## 1. Mục Tiêu (Objective)
Vá lỗi Permission Bug liên quan đến quyền `payroll.publish` trong hệ thống phân quyền (RBAC) mà không gây ảnh hưởng đến dữ liệu Production hiện tại. 

## 2. Lỗi Phát Hiện (Bug Description)
API Endpoint `POST/PATCH /api/hr/payroll/publish` kiểm tra quyền `payroll.publish`. Tuy nhiên, script khởi tạo database `seed_payroll_permissions.ts` đã quên gán quyền này cho bất kỳ Role nào. Hậu quả là kể cả ADMIN và ACCOUNTANT đều bị hệ thống chặn (HTTP 403) khi cố gắng công bố bảng lương.

## 3. Bản Vá Mật Mã (Source Code Fix)
- Đã chỉnh sửa trực tiếp file `scripts/seed_payroll_permissions.ts` (Nguồn chân lý - Source of Truth).
- Thêm `PERMISSION_PAYROLL_PUBLISH` vào danh sách `NEW_PERMISSIONS`.
- Map quyền này trực tiếp vào `ROLE_MAPPINGS` cho 2 role:
  - `ADMIN`
  - `ACCOUNTANT`
- Các Role khác như `VIEWER`, `MANAGER`, `WORKER`, `DESIGNER`, `STAFF` hoàn toàn không được map quyền này.
