# P0.UI-ARCH-FINAL

## Mục tiêu hoàn thành
P0.UI-ARCH đã được hoàn thành.
Toàn bộ UI của HomePro Manager đã được tái cấu trúc thành một ERP UI Architecture với cấu trúc configuration-driven.

## Thành quả
1. **Module Navigation Config**: Đã chuyển `Sidebar.tsx` sang sử dụng navigation config (`src/config/navigation.ts`).
2. **Workspace Isolation**: Tách biệt các module vào các Workspace độc lập (Dashboard, Điều hành, Nhân sự, Tài chính - Kế toán, Dự án, Vật tư - Kho, Sản xuất, Hệ thống).
3. **AppShell & LayoutWrapper**: Định hình cấu trúc AppShell chung, xử lý ẩn/hiện Sidebar tự động theo workspace / loại user (đặc biệt cho Worker Portal `/nhan-vien`).
4. **Validation**: 
   - Đã sửa lại code Worker Portal gửi đúng API value cho Leave Type (ANNUAL, SICK, UNPAID).
   - Đã chạy thành công bộ UAT P0.14 trên môi trường Production (tất cả 8 role).
   - Đã chạy thành công bộ UAT P0.18 Leave Approval trên môi trường Production.
   - Không phá vỡ bất kì logic nghiệp vụ nào từ Auth, RBAC, đến Leave, Attendance hay Payroll.

## FREEZE UI FOUNDATION
- **UI Architecture Foundation is now FROZEN**.
- Mọi module mới từ đây về sau phải tuân thủ kiến trúc đã thiết lập.
- Không tự tiện hardcode link menu vào `Sidebar.tsx` nữa. Bất kì menu nào cũng phải được khai báo trong `navigation.ts`.
- `LayoutWrapper.tsx` đã xử lý các trang "clean" không có Sidebar (`/login`, `/nhan-vien`, `/attendance-gate`). Không chỉnh sửa unless thực sự cần thiết.
